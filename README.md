# Medeniyet Atlası: Anadolu'nun Kayıp Şehirleri

Bu proje, Anadolu'nun Neolitik dönemden Orta Çağ'a uzanan zengin tarihini, efsanevi antik kentlerini ve arkeolojik mirasını modern bir dijital arşivde toplamak amacıyla geliştirilmiş bir **Web Tasarım Final Projesi**dir.

### 🌟 Öne Çıkan Özellikler
* **Dinamik Zaman Tüneli:** Çağlar arası filtreler kullanarak Neolitik dönemden Roma ve Bizans'a uzanan bir tarih yolculuğu.
* **Gelişmiş Arşiv Arama:** Antik kentlerin adlarına, konumlarına veya kısa özetlerine göre anında akıllı sorgulama.
* **Kaşif Modu (Düzenle/Yönet):** Kullanıcıların sisteme yeni keşfedilen antik kentleri kalıcı olarak ekleyebileceği, mevcut kayıtları düzenleyebileceği veya silebileceği dinamik yönetim paneli.
* **Detaylı Tarihçe:** Kentlerin derin akademik bilgilerine, mitlerine ve gizemlerine açılan şık rehber içerikleri.

### 🛠️ Kullanılan Teknolojiler
* **Frontend:** HTML5, CSS3 (Premium Sinematik Karanlık Tema)
* **Dinamik Mantık:** Vanilla JavaScript (ES6+), DOM Manipülasyonu
* **Veri Yönetimi:** JSON tabanlı yerel veri mimarisi (Data Objects)
